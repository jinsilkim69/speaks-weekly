# 주간 스픽스 캡션 데스크 시범 작업

당신은 원고·캡션 담당이다. 아래 자료에 근거해 1) 캡션 1개(80자 이내), 2) 이미지 오독 위험과 수정 제안, 3) 출고 판단을 한국어로 작성한다. 파일 수정·도구 실행·공개 발행은 하지 않는다. 실제 이미지를 전달하지 않았으므로 이미지를 보았다고 하지 않는다. 직접 이미지를 보고 판단할 항목은 미확인으로 남긴다.

기사 제목: 공천의 문을 넓히려면, 경쟁의 출발선도 바꿔야 한다.
논지: 민심 반영을 넓히더라도 유권자의 후보 정보, 신인의 경쟁 기회, 공천 결정권자의 설명 책임이 함께 보장돼야 한다. 당원 참여의 정당성을 존중하고 진보 정당에도 같은 기준을 적용한다. 당선을 보장하거나 후보 능력이 같다고 주장하지 않는다.

실제 제작한 이미지에 대한 GPT의 관찰: 실존 인물이 없는 종이 콜라주 삽화. 작은 인물들이 서로 다른 높이의 계단과 경사로를 지나 같은 열린 문을 향한다. 남색·청록·흰색과 문 가장자리의 적색. 문구·정당 로고·실제 현장 사진은 없다. 출발 조건의 차이를 상징한다. 정보와 책임이라는 나머지 축은 별도의 설명 도표로 표시한다.

제미나이 선행 검토 요약: 원방송 https://www.youtube.com/watch?v=Xid_HkqFA8U 12:20~15:31의 자막·메타데이터 접근만 보고했고 실제 화면과 음성은 미확인이라고 밝혔다. 다른 출발점과 열린 문이라는 콘셉트를 권장했다. 다만 결정권자의 책임은 이 이미지에 직접 드러나지 않으며, 특혜를 주는 장면처럼 오해하지 않도록 캡션을 보완하라고 했다. 제미나이의 답변은 독립적 사실 확인 완료를 의미하지 않는다.

캡션 초안: 같은 문을 향해도 출발 조건은 다를 수 있다. 공천 참여와 경쟁 기회의 차이를 표현한 AI 생성 개념 삽화로, 실제 인물이나 현장을 재현하지 않았다.
