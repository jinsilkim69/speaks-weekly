# 주간 스픽스

Node.js 기반 웹 매거진과 50페이지 전자책 미리보기 프로젝트입니다.

## 실행

```sh
npm ci
npm start
```

기본 주소는 `http://localhost:3000`이며 `/magazine`은 전자책, `/admin`은 편집 화면입니다. 서버는 기본적으로 로컬 주소에만 바인딩됩니다. 원격 공개 전에는 별도의 관리자 인증이 필요합니다.

```sh
npm test
npm run pipeline
npm run export
```

`pipeline`은 이제 내장 에이전트가 작성한 원고를 반영합니다. URL을 넘기면 실제 방송 자막을 수집하고 에이전트 집필 대기 상태를 반환합니다. 고정 샘플 생성은 테스트용 `--demo` 옵션에서만 실행됩니다. 테스트는 임시 복사본에서 실행합니다. `export`는 `dist`에 정적 사이트를 생성합니다. 정적 사이트에서는 편집 저장과 파이프라인 실행이 불가능하며 로컬 서버에서 이용해야 합니다.

## API 없이 제작하는 순서

설계 기준은 `AGENTS.md`입니다. 구독형 AI의 내장 에이전트가 분석과 집필을 담당하며, Node 스크립트가 자동으로 다른 AI 구독 계정을 실행한다고 가정하지 않습니다.

1. 로컬에 `yt-dlp`가 설치된 환경에서 `npm run collect:broadcast -- "스픽스 방송 URL"`을 실행합니다. 공식 채널 여부를 확인하고 한국어 자막을 `data/research/영상ID.json`에 타임스탬프별 구조화 자료로 저장합니다. 원시 임시 파일은 성공·실패 모두 정리합니다.
2. 내장 에이전트가 자료를 읽고 `data/agent_articles.json`에 실제 원고를 작성합니다. 출처 ID, 근거 시간 범위, 본문, 검증 범위를 반드시 포함합니다. 자막 오류, 출연자의 주장, 확인된 사실을 구분합니다.
3. `npm run publish:agent`로 기사와 지면에 반영합니다. 대응하는 수집 자료와 유효한 근거 시간이 없으면 발행을 중단합니다. 이 명령은 기존 편집 결과를 갱신하므로 변경은 Git으로 관리합니다.
4. `npm test`와 브라우저 확인 후 `npm run build`를 실행하고 GitHub에 푸시합니다. Cloudflare는 갱신된 정적 사이트를 배포합니다.

현재 편집본에는 2026년 10월 26일 스픽스 ‘역전의용사들’ 방송 1편을 분석한 기사 3건이 있습니다. 14개 꼭지·50페이지 중 나머지는 취재·편집 대기이며 완성호가 아닙니다. 구조화 자막 전체는 Git에서 제외하고, 공개 발행 데이터에는 방송 메타데이터와 기사 근거 시간만 포함합니다. 다른 컴퓨터에서 원고를 다시 반영하려면 원천 방송을 먼저 수집해야 합니다.

## 현재 구현 범위

- 공식 YouTube 방송의 한국어 자막 수집과 내장 에이전트 원고 반영은 구현했습니다. 자막이 없으면 성공으로 처리하지 않습니다.
- 신문 기사 수집, 주간 전체 방송 자동 선별, 스틸컷/Heatmap 추출, 정기 발행 스케줄은 아직 연결되지 않았습니다. AI API는 사용하지 않습니다.
- 실제 기사에는 자동 자막 기반이라는 점과 검증 범위를 표시합니다. 방송 내용의 독립적 사실 확인이 모두 완료되었다고 주장하지 않습니다.
- 전자책은 브라우저 인쇄 화면을 제공합니다. PDF 자동 생성 및 실제 출력의 50페이지·넘침 여부 검증은 아직 구현되어 있지 않습니다.
- QR은 동봉한 MIT 라이선스 `qrcode-generator`의 표준 인코더를 사용합니다. QR로 이동하는 원천 URL의 보도 내용까지 검증하는 것은 아닙니다.
- 판권지 식별번호는 사용자 지정 값을 그대로 표시합니다. 유효성 확인 없이 바코드를 만들어 내지 않습니다.

## 수정 및 검증

누락된 시각화 모듈 내보내기, 관리자 저장 요청 형식, 기사/지면 동기화, 미리보기 페이지 링크, 잘못된 JSON 처리, 입력 구조 검증, 파일 저장 중 손상 방지, 공개 폴더 밖 경로 접근, 타 사이트의 저장 요청, 사용자 원본 자막을 삭제하던 임시 파일 정리를 수정했습니다.

QR 라이브러리의 배포 파일은 브라우저와 정적 호스팅에서 동일하게 사용하도록 `public/js/vendor/qrcode.mjs`에 포함했습니다. 원본 라이선스 주석을 보존했으며 패키지 버전은 `package-lock.json`으로 고정합니다.
