# 정기 제작 실행 지침 — 2026-10-28 개정

홈페이지 ‘스픽스 리뷰’는 공식 기사 제목과 원문 링크를 안내한다. 별도 홈페이지 리뷰 집필은 중단하고 제작 역량을 주간지에 집중한다. 이 기준은 이전의 일간 1~2개 자체 기사 목표와 회차별 축약 원고 규칙을 대체한다. docs/program-first-home.md와 skills/speaks-weekly-writing/SKILL.md를 적용한다. 기존 원고·발행호·사용자 변경을 보존하며 API 키를 추가하지 않는다.

## 실행과 중복 방지

node scripts/production-cycle.mjs begin daily 또는 begin weekly를 먼저 실행한다. skip=true면 중복 실행하지 않는다. 오래된 running 상태는 프로세스·결과를 확인하고 실패 기록으로 finish한 뒤 재시도한다. 실행 중인 잠금을 강제로 덮어쓰지 않는다. 결과 JSON의 id,state,summary,steps를 node scripts/production-cycle.mjs finish 결과.json으로 기록한다. 수집·검토 완료와 새 발행을 구별한다.

4. 원방송·다시보기·클립을 대조해 같은 회차를 중복 취재하지 않는다. 원문이 짧거나 연결 페이지만 있으면 본문·자막을 추가 확보한다. 진행 중 생방송을 완성 방송으로 처리하지 않는다. 원시 음성·자막은 구조화 후 정리한다.
5. 주간지 후보별 핵심 주장·화자·근거 위치·필요한 배경·사진 계획을 정리한다. 홈페이지용 별도 요약 원고나 20% 축약본은 새로 만들지 않는다. 검토된 주간지 원고만 발행호에 편성한다.

## 실제 AI 분업

- Gemini 구독 웹 앱: 확보한 기사·자막을 읽고 핵심 주장·화자·시각·배경 자료와 사진 후보를 조사한다. 링크 전달과 실제 영상 청취를 구별한다. 요청에서 3분 이상 응답이 없거나 로그인·한도가 막히면 실패/부분 완료를 기록한다.
- GPT: 원문 대조, 조사 오류 교정, 주간호 편성, 사진의 날짜·권리·맥락 확인, 필요한 삽화 생성, 최종 원고와 지면 검수. 서비스 실패 시 확보 원문을 대행하고 범위를 명시한다.
- Claude 구독 CLI: scripts/claude-desk.mjs에 실제 원문·조사 인계·집필 스킬·이미지 기획을 전달해 주간지 원고·캡션을 집필한다. 조사 이전 초고는 조사 이후 다시 데스킹한다. API 인증으로 우회하지 않는다.
- productionHandoff에는 원문 SHA, 실제 조사 완료/대행 범위, 집필 실행 기록, 최종 검수 해시를 남긴다. 미실행 AI를 완료로 기록하지 않는다. 현재 assertProductionHandoff는 Claude 완료 근거를 요구하므로 Claude 실패 대행은 그 검증을 통과한 것으로 표시하지 않고 별도 검토 기록과 출고 판단을 남긴다.

## 일요일 18:00 마감·월요일 06:00 발행 KST

- 주간호는 검토된 다양한 분야의 꼭지와 발행인의 말로 편성한다. 꼭지 수를 14개로 고정하지 않는다. 50쪽은 제한이 아니다. 원고·사진·삽화의 읽기 좋은 배치에 따라 면수를 늘린다. 본문은 양쪽 맞춤이다. 사진의 권리·날짜·맥락, 삽화의 생성 표시·역할, 도표의 실제 수치·범위를 검토한다.

## 사용자 검수 완료 후 PDF 발행 — 2026-10-29 최우선

자동 제작은 미발행 편집본 준비까지다. 사용자가 로컬 관리자에서 원고를 검수하고 `완료 · PDF 발행 승인`을 직접 누르기 전에는 공개 PDF를 발행·배포하지 않는다. 일반 검토 기록 저장은 발행 승인이 아니다. AI는 사용자 대신 완료를 누르거나 승인 기록을 생성하지 않는다.

`completeDeskEdition`은 현재 저장 버전의 사용자 확인과 검토 메모를 받아 승인 지문과 queued 발행 요청을 남긴다. `releaseEdition`은 관리자에 실제 저장된 승인과 현재 원고·사진·순서·조판 설정이 일치하는지 재검사한다. 페이지 수는 이후 조판으로 결정되지만 본문과 이미지는 바뀌면 안 된다. 수정·저장은 승인을 해제하며 다시 사용자 검수를 받아야 한다.

완료 후에는 PDF 조판과 원문·문체·이미지·전 면 시각·QR 검사를 거쳐 발행한다. 완료가 품질 검사 생략을 뜻하지 않는다. 미승인 호는 월요일 정기 발행 시간이 되어도 대기한다. 일요일 전 승인 호는 발행 예정일에, 이미 예정일이 지난 승인 호는 다음 제작 실행에서 처리한다. 홈페이지 공식 기사 링크 갱신은 계속한다.

발행인 전계완, 편집장 김진실(철학박사), 제작 도서출판 아우내로 표기한다. 사람 책임자와 AI 기자 필명을 구별한다. 새 주간호의 첫 본기사는 「편집장의 시선」 고정 논평으로 편성한다. 김진실 편집장 명의의 AI 보조 초안은 검수 전 미발행으로 보관하고, 사용자 승인 뒤에만 편집장 명의로 발행한다. 한 주의 사실을 꿰는 분명한 질문·논증·정책적 선택을 담고 발간 인사나 기사 요약 나열, 철학자 이름과 추상어의 장식은 피한다. 인간의 존엄·자율적 협력·공공의 책임을 구체적인 현실에서 풀어낸다. 신규 주간호 staff에 책임자 표기를 담아 PDF 판권과 승인 지문에 결합하며 기존 발행 PDF는 보존한다.

## 콘텐츠 확장 — 최신 편성 기준

품격·깊이·철학을 차별점으로 삼고 시사IN을 취재와 지면의 경쟁 기준으로 삼는다. 14~18개 꼭지는 유연한 목표다. 편집장 논평, 커버·심층 기획, 방송 지상중계와 정치·경제·사회·국제·지역·문화, 만평 및 짧은 책·인물·숫자 코너를 조합한다. 스픽스 자료뿐 아니라 확인 가능한 공공 자료와 당사자 의견을 찾아 범위를 넓힌다. 기사 수를 위해 중복 집필하거나 확인하지 않은 현장·인터뷰를 꾸미지 않는다. 심층 본기사는 5,000~7,000자를 지향하되 논평·단신·만평 등은 성격에 맞게 편성한다. 출처·이미지·사실 확인이 부족하면 사용자 검토용 대기로 남긴다. 미승인 콘텐츠는 PDF나 홈페이지 발행호에 넣지 않는다.
