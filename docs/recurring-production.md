# 정기 제작 실행 지침 — 2026-10-28 개정

홈페이지 ‘스픽스 리뷰’는 공식 기사 제목과 원문 링크를 안내한다. 별도 홈페이지 리뷰 집필은 중단하고 제작 역량을 주간지에 집중한다. 이 기준은 이전의 일간 1~2개 자체 기사 목표와 회차별 축약 원고 규칙을 대체한다. docs/program-first-home.md와 skills/speaks-weekly-writing/SKILL.md를 적용한다. 기존 원고·발행호·사용자 변경을 보존하며 API 키를 추가하지 않는다.

## 실행과 중복 방지

node scripts/production-cycle.mjs begin daily 또는 begin weekly를 먼저 실행한다. skip=true면 중복 실행하지 않는다. 오래된 running 상태는 프로세스·결과를 확인하고 실패 기록으로 finish한 뒤 재시도한다. 실행 중인 잠금을 강제로 덮어쓰지 않는다. 결과 JSON의 id,state,summary,steps를 node scripts/production-cycle.mjs finish 결과.json으로 기록한다. 수집·검토 완료와 새 발행을 구별한다.

2. 실제 공식 페이지에서 제목·날짜·코너·원문/영상 연결을 대조한다. 목록 페이지 반복·403·누락은 내부 기록에 남기며 잘못된 링크나 추측한 날짜로 빈칸을 채우지 않는다. 목록이 바뀐 경우에만 build·GitHub push·공개 페이지 확인으로 안내 목록을 반영한다. 단순한 확인 시각 변경만으로 매번 재배포하지 않는다.
3. 한 주 주간지에 필요한 주요 방송·신문 원문을 골라 준비한다. npm run editorial:prepare -- daily 기준일 --refresh는 전날 후보를 찾으므로 오늘 자료는 다음 날짜를 asOf로 지정한다. editorial:collect로 실제 본문·자막을 확보한다. 제목·썸네일만 보고 원고를 쓰지 않는다.
4. 원방송·다시보기·클립을 대조해 같은 회차를 중복 취재하지 않는다. 원문이 짧거나 연결 페이지만 있으면 본문·자막을 추가 확보한다. 진행 중 생방송을 완성 방송으로 처리하지 않는다. 원시 음성·자막은 구조화 후 정리한다.
5. 주간지 후보별 핵심 주장·화자·근거 위치·필요한 배경·사진 계획을 정리한다. 홈페이지용 별도 요약 원고나 20% 축약본은 새로 만들지 않는다. 검토된 주간지 원고만 발행호에 편성한다.

## 실제 AI 분업

- Gemini 구독 웹 앱: 확보한 기사·자막을 읽고 핵심 주장·화자·시각·배경 자료와 사진 후보를 조사한다. 링크 전달과 실제 영상 청취를 구별한다. 요청에서 3분 이상 응답이 없거나 로그인·한도가 막히면 실패/부분 완료를 기록한다.
- GPT: 원문 대조, 조사 오류 교정, 주간호 편성, 사진의 날짜·권리·맥락 확인, 필요한 삽화 생성, 최종 원고와 지면 검수. 서비스 실패 시 확보 원문을 대행하고 범위를 명시한다.
- Claude 구독 CLI: scripts/claude-desk.mjs에 실제 원문·조사 인계·집필 스킬·이미지 기획을 전달해 주간지 원고·캡션을 집필한다. 조사 이전 초고는 조사 이후 다시 데스킹한다. API 인증으로 우회하지 않는다.
- productionHandoff에는 원문 SHA, 실제 조사 완료/대행 범위, 집필 실행 기록, 최종 검수 해시를 남긴다. 미실행 AI를 완료로 기록하지 않는다. 현재 assertProductionHandoff는 Claude 완료 근거를 요구하므로 Claude 실패 대행은 그 검증을 통과한 것으로 표시하지 않고 별도 검토 기록과 출고 판단을 남긴다.
