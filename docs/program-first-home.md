# 홈페이지와 PDF의 편집 단위

2026-10-27 사용자 추가 지시를 기존 주제별 홈페이지 설계보다 우선 적용한다.

| 구분 | 홈페이지 | 주간지 PDF |
| --- | --- | --- |
| 기본 단위 | 코너와 개별 방송 회차 | 한 주의 주제와 기획 |
| 독자의 질문 | 내가 보는 코너에서 이번 회에 무슨 이야기를 했나 | 이번 주 주요 사안을 여러 방송이 어떻게 다뤘나 |
| 구성 | 요일별 방송 목록 → 코너 → 최신·지난 회차 | 여러 코너·회차를 연결한 커버스토리·분야별 지면 |
| 원고 | 회차 전체의 핵심 결론·주장·이유·논의 흐름 소개 | 관련 회차를 재편집하고 배경·자료를 더한 주제 기사 |
| 원방송 | 회차별 원영상과 실제 확인한 시간표시 | 인용한 모든 코너·회차·화자·원출처 |

## 홈페이지 구성 기준

- 첫 화면에서 요일별 방송과 코너별 최신 회차를 찾을 수 있게 한다. 고정 편성표가 확인되기 전에는 실제 방송일을 요일로 묶어 보여 주고 이를 매주 고정 편성이라고 부르지 않는다.
- 코너 페이지에는 코너 소개, 확인된 진행자·출연자, 확인된 편성 정보, 최신 회차와 지난 회차를 둔다. 회차마다 출연자가 다를 수 있다.
- 회차 소개는 핵심 결론을 먼저 전하고 주요 대화의 흐름을 충분히 정리한다. 한 방송이 여러 주제를 다뤘다면 한 회차 안에서 소제목으로 나눈다.
- 짧은 클립과 다시보기는 가능하면 본방송 회차에 연결한다. 제목이나 영상 ID가 다르다는 이유만으로 서로 다른 회차로 집계하지 않는다.
- 원방송 연결, 방송일, 출연자, 수집·검토 상태를 보존한다. 미확보 회차를 소개 완료로 만들지 않는다.
- 신문 칼럼은 홈페이지 코너별 방송 소개를 대체하지 않으며 별도 보충 읽을거리로 구분한다.

## 제작 데이터의 구분

- 코너: 고유 ID, 공식 이름·별칭, 설명, 공식 원출처, 확인한 고정 편성 및 근거. 미확인 요일·시간은 비워 둔다.
- 회차: 코너 ID, 원방송 ID·URL, 실제 방송일, 진행자·출연자, 제목, 전체 논의 목록, 핵심 소개 원고, 검토 상태, 관련 클립.
- 주간호: 대상 기간, 주제별 기사, 각 기사가 참고한 회차 목록. 회차 소개를 그대로 합친 PDF로 끝내지 않는다.

## 메뉴와 공개 범위

- 제호 아래 큰 메뉴는 **스픽스 리뷰**(`/`)와 **주간지 기사 보기**(`/?view=weekly`) 두 개다.
- 리뷰는 월~일을 항상 펼친다. 요일 선택기 없이 PC에서는 7열, 휴대전화에서는 요일별 세로 목록으로 보여 준다. 각 코너에 리뷰·원본 영상 연결을 나란히 둔다.
- 고정 편성 근거를 확보하기 전에는 실제 방송일로 묶고 이를 화면에 명시한다. 특집인터뷰는 특집·수시 방송으로 별도 배치한다. 비어 있는 날은 방송이 없다는 뜻이 아니라 검토된 회차가 아직 없다는 뜻이다.
- 코너별 원고 10회와 신문 보충 기사 2편을 연결한다. 기본 표시 주간(2026.10.19~25)은 방송 9회를 월~일에 배치하며 26일 방송은 해당 주 목록에 섞지 않는다. 전체 채널 편성이 모두 등록된 상태는 아니다. 공식 고정 편성표·시간과 추가 코너는 근거 확보 후 등록한다.
- 주간지 메뉴는 한국 시간으로 현재 주 월요일 이전에 대상 기간이 끝난 발행호 가운데 가장 최근 호의 최신 교정판을 연다. 기사 14편은 발행 스냅샷 본문을 그대로 읽고 PDF도 연다. 웹 리뷰의 축약본으로 대체하지 않는다.
- 2026-10-27 출고: 홈페이지 원고는 기존 대비 19.5~21.5% 축약. 실제 사진 5점의 날짜·출처·이용 조건을 확인하고 생성 삽화와 구분했다. 이전 발행호는 보존하며 기본 링크는 교정판으로 안내한다.
