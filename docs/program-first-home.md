## 공식 기사 안내

- 월~일을 항상 펼친 기존 구성을 유지한다. 각 요일 아래 코너명, 공식 제목, ‘스픽스 원문 읽기’, 확인된 경우 ‘원본 방송 보기’를 둔다. 원본 링크는 붉은 글씨이며 박스를 쓰지 않는다.
- data/official-links.json은 자체 집필 기사와 독립된 목록이다. 제목은 공식 페이지 h1.heading에서 확인하며 verifiedTitle과 같아야 한다. OG 제목의 사이트명이나 목록의 줄임표를 기사 제목으로 대체하지 않는다.
- 본문에 방송일이 명시돼 있으면 그 날짜에 배치한다. 방송일을 확인할 수 없으면 입력일로 배치하고 ‘기사 게시 · 방송일 미확인’이라고 표시한다. 고정 요일·시간을 추측하지 않는다.
- 링크는 공식 기사 URL만 허용한다. 영상은 해당 기사의 실제 iframe에서 확인한 주소만 표시한다. 과거 리뷰의 비슷한 주제 영상으로 바꾸지 않는다.
- 같은 기사 URL은 한 번만 등록한다. 한 방송에 공식 기사가 여럿 있으면 기사 수로 세며 방송 회차 수로 과장하지 않는다. 클립·본방송 관계는 주간지 원자료 조사에서 확인한다.
- npm run links:refresh로 갱신한다. 새 항목의 제목·코너·날짜 기준·원문 연결을 검수한 뒤 build·push·공개 열람 확인을 한다. 오류 때 기존 정상 목록을 보존한다. 공식 목록 페이지가 반복되면 수집 범위 한계를 기록하며 전체 채널 수집 완료로 표시하지 않는다.
- 현재 화면의 주간은 확보한 공식 기사 중 가장 최근 기준 날짜가 속한 월~일이다. 아래 코너별 목록에서는 이전 기사도 찾을 수 있다. 빈 요일은 방송 부재가 아니라 확인한 연결 기사 부재를 뜻한다.
- 기존 data/web_articles.json과 이전 #article 링크는 보존한다. 새 홈페이지에서 자체 리뷰를 새로 집필·홍보하지 않으며, 발행호 스냅샷은 변경하지 않는다.

## 주간지 중심 제작

공식 기사 목록은 발견·안내용이다. 제목이나 링크만으로 주간지를 쓰지 않는다. 기사 본문을 읽고 필요하면 방송 자막·원음을 확보한다. Gemini 조사 → GPT 원문 대조·이미지 기획 → Claude 집필 → GPT 핵심 보존·사실·문체·이미지 검수로 진행하며 실제 수행 범위를 기록한다. 구독 서비스 실패 시 확보 원문을 내장 GPT가 대행하되 대행 범위와 사유를 남긴다.

방송을 보기 어려운 독자에게 핵심 주장·이유·사례·대화 흐름을 전한다. 자체 비평·공허한 평가를 보태지 않는다. 단순 합본 대신 주제별 연결과 쉬운 배경 설명을 더한다. 50쪽은 제한이 아니며 원고와 시각자료에 맞춰 조판한다. 웹 주간지와 PDF는 같은 발행 스냅샷을 제공한다.
