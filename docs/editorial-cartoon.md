# 위클리 스픽스 시사만평

2026-10-29 사용자가 비교 시안의 A안 ‘절제된 펜화’를 선택했다. 실제 기준은 data/editorial/cartoon-style.json에 있다. 이 선택은 개별 만평의 출고 승인을 뜻하지 않는다.

검은 잉크의 굵기 변화와 생략, 흰 종이, 제한된 남색·회색, 필요한 대목의 작은 적색을 기본으로 한다. 시민의 눈높이에서 권력·정책·제도의 모순을 한 장면에 담는다. 시민을 조롱하거나 지지 정치인을 영웅화하지 않는다. 실제 인물의 외모보다 행동과 상황을 풍자한다. 국내외 만평의 시각적 압축과 비유 원리를 참고하며 특정 작가의 화풍·구도·서명을 복제하지 않는다.

한 주의 핵심 쟁점 한 건으로 시작한다. Gemini는 원문과 당사자 입장 조사, Claude는 시각적 비유·대사 3안, GPT는 이미지 생성과 실제 시각 검수를 맡는다. 실제 수행·대행 범위를 기록한다. 세 서비스의 완전 무인 연동을 완성한 것으로 표시하지 않는다. 원화와 말풍선 글자는 별도 조판해 한국어 오탈자를 막는다. 풍자 대사를 실제 발언으로 표시하지 않는다.

만평은 해당 기사의 supportingVisuals에 generated-illustration으로 넣고, AI 시사만평 표시·대체 설명·제작 도구·프롬프트·원출처와 권리 기록을 남긴다. 이렇게 등록한 파일의 해시도 사용자 발행 승인에 결합된다. 개별 만평과 원고는 관리자에서 사용자 검수 완료 전 공개하지 않는다. 만평을 바꾸면 재승인을 받아야 한다.
