# 사진·이미지 편집 데스크

## 역할과 실제 실행

- **Gemini — 방송·사진 리서치:** 자막·음성·화면 중 실제 접근한 범위를 밝힌다. 주장별 시간표시, 사진 후보의 원출처·날짜·장소·인물, 스틸 후보 시각을 제시한다. 검색 결과에 나온 이미지를 곧바로 사용 허락된 사진으로 취급하지 않는다. 화면 미확인이면 후보일 뿐이다. 현재 구독 웹 앱에서 실행하며 결과를 편집 기록으로 저장한다.
- **GPT — 편집 기획·아트디렉션:** 원고의 중심 질문에 맞는 이미지 종류와 역할을 결정한다. 사진은 원출처에서 조건을 확인해 확보하고, 방송 스틸은 실제 구간을 확인해 선택한다. 삽화는 내장 image_gen으로 생성한다. 숫자·비교표·타임라인은 근거 데이터로 SVG/차트 코드로 만든다. 생성 그림 안에 통계를 그려 사실 그래프로 사용하지 않는다.
- **Claude — 집필·캡션 데스크:** Gemini 자료와 GPT 시각 기획을 받아 원고·캡션·반론을 검토한다. 사진 설명의 주체·시점·행동이 근거와 같은지 확인한다. 실제 이미지를 받지 않았다면 텍스트 기획 검토라고 밝힌다. 현재 구독 로그인된 Claude CLI로 텍스트 작업이 가능하다.
- **GPT — 최종 출고:** 실제 이미지와 웹·인쇄 크기를 보고 오독, 잘림, 작은 글자, 출처, AI 표시를 점검한다. 다른 모델의 승인을 대신 적지 않는다. 발행 시 이미지 메타데이터도 원고 검토 해시에 포함한다.

Gemini와 Claude는 각각의 구독 화면/CLI에서 실행한다. 별도 유료 API 키를 넣거나 스크립트 이름만으로 실행됐다고 표시하지 않는다. 연결 실패·구독 한도는 해당 단계의 실패로 기록하고, 다른 모델이 대행했으면 실제 작업자를 기록한다. 현재 이 분업은 시범 실행했으며 무인 정기 인계 전체를 완성한 것은 아니다.

## 장르에 따른 선택

| 기사 | 대표 이미지 | 본문 보조 이미지 |
|---|---|---|
| 사건·현장·지역 | 날짜·장소가 확인된 보도 사진 | 다른 시점의 현장, 지도, 근거 문서 |
| 인물·실제 인터뷰 | 인터뷰 인물의 실제 사진 또는 검토한 방송 스틸 | 대담 장면, 관련 현장 사진 |
| 제도·경제 분석 | 논지를 압축한 삽화 또는 실물 사진 | 근거가 있는 비교표·타임라인·구조도 |
| 문화·여행·서평 | 실제 장소·작품·표지의 사용 가능한 사진 | 세부 사진, 지도, 자료 이미지 |
| 방송 소개·발언록 | 원방송 썸네일 또는 스틸 | 원방송 연결용 작은 미리보기 |

썸네일은 선택지 중 하나다. 대표 이미지 자동 기본값으로 고정하지 않는다. 한 기사는 대표 이미지 1개와 필요에 따른 보조 이미지 1~3개를 기획하되, 정보가 늘지 않으면 추가하지 않는다. 같은 사진 반복, 의미 없는 국회의사당·악수·저울 이미지, 자극적인 유튜브 자막을 모든 지면에 반복하는 방식을 피한다.

## 시사주간지 스타일을 적용하는 방법

확인 사례: [시사IN 인터뷰](https://www.sisain.co.kr/news/articleView.html?idxno=58662)에서 인물 사진·부산항·비탈길의 시민 사진이 서로 다른 질문에 대응한다. 캡션에는 대상·맥락과 촬영자 표시가 있으며 본문 질문과 사진이 번갈아 호흡을 만든다. [시사IN 사진 섹션과 홈페이지](https://www.sisain.co.kr/)는 사진 보도와 해설·인터뷰를 구별한다. 이 관찰을 아래 자체 편집 기준으로 옮긴다. 다른 매체 사진·디자인을 복제하지 않는다. 한겨레21 사이트는 이번 도구에서 접근이 제한되어 실제 지면 확인 완료로 기록하지 않는다.

- 대표 이미지는 기사의 질문 하나를 전달한다. 제목을 이미지에 다시 큰 글자로 쓰지 않는다.
- 본문 이미지는 관련 설명 가까이에 배치하고, 캡션이 무엇을 보여주는지 설명하게 한다.
- 보도 사진, 방송 스틸, 생성 삽화, 설명 도표를 독자가 구분할 수 있게 표시한다.
- 웹은 가로 3:2 또는 자료 고유 비율을 존중하고 모바일에서 얼굴·문서·축을 임의로 자르지 않는다. 표지용 세로 이미지는 별도 구도로 제작한다.
- PDF는 실제 배치 폭과 원본 픽셀로 유효 해상도를 계산한다. 예: 가로 1536px 이미지는 300dpi에서 약 130mm 폭이다. 이를 A4 전면 300dpi 원본이라고 주장하지 않는다.
- 사진은 원래 맥락을 바꾸는 합성·생성 채우기·인물 제거를 하지 않는다. 필요한 밝기 보정·크롭은 기록한다.
- 생성 삽화로 실제 정치인의 행동·사건 현장·증거 문서를 만들어 보도 사진처럼 사용하지 않는다. 생성 표시와 제작 프롬프트를 보존한다.

## 출고 데이터

대표 이미지는 article.visual, 본문 보조 이미지는 article.supportingVisuals 배열이다. 보조 이미지는 afterParagraph(0부터 시작)를 갖는다. 각 이미지에 kind, purpose, url, width, height, alt, caption, credit, rights가 필요하다.

kind: photo / video-still / thumbnail / generated-illustration / diagram.

rights에는 status:cleared, basis:original-work|permission|license, 구체적인 note를 기록한다. 허락·라이선스는 referenceUrl을 함께 남긴다. 출처 표기만으로 사용 허락을 대체하지 않는다. 스픽스와의 제휴 계획을 체결된 이미지 이용 허락으로 취급하지 않는다.

사진·스틸·썸네일에는 sourceUrl과 context가 필요하다. 방송 스틸은 timestamp(초)도 필요하다. 생성 삽화는 disclosure에 AI 표시, generation에 실제 tool과 prompt를 남긴다. 자료 이미지는 원문을 읽을 수 있어야 한다. 출처 미확인 자료는 후보로 보관하고 공개 출고하지 않는다.
